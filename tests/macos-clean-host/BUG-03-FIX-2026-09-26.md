# BUG-03: verify and repair activation links

Doctor now checks the active generation's immutable state and activation tree.
It reports link damage and states that it does not check store contents.
Verify-only repair refuses missing, changed, or additional activation entries.
Mutating repair first verifies or repairs the store closure through the broker,
then rebuilds the local tree from the committed state and recorded collision
policy. The replacement must match the recorded digest before it is published.

Repair keeps a bounded backup during directory replacement. A later repair can
restore that backup after interruption. GC removes these backup paths before
releasing generation roots. No generation, root set, or package selection changes.

This fix is local and unreleased. The [original audit](BUG-HUNT-2026-09-26.md)
records the failing behavior. Release work remains deferred.
