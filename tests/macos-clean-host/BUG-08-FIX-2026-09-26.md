# BUG-08: refuse unsupported remove orphan checks

Remove now rejects `--orphan-check` with 78/CONFIG before target selection,
recovery, approval, or broker access. The pure state editor also refuses it.
Help and the hint direct users to GC preview after removal. Ordinary remove
results no longer include the misleading `orphanCheckRequested` field.
This uses the explicit refusal remedy in the [original audit](BUG-HUNT-2026-09-26.md).

The fix is local and unreleased. Release work remains deferred.
