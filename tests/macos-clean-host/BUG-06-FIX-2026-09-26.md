# BUG-06: validate install previews against current state

Install preview now reads validated current state under a shared lease. It refuses
pending recovery and selectors already installed. A read-only activation planner
checks installed outputs with the requested collision policy. Real staging uses
the same planner and exact selector/output bindings.

Preview identifies its source generation. Human and JSON output explicitly defer
new-output collisions and final state revalidation until acquisition. A preview
is not a guarantee that activation will succeed. No staging tree is written.

This fix is local and unreleased. The [original audit](BUG-HUNT-2026-09-26.md)
records the failure. Release work remains deferred.
