# BUG-09: keep shell MANPATH setup idempotent

The Bash/zsh snippet now adds the pkg man directory only when it is absent.
Repeated evaluation preserves the system-default empty entry and custom entries.
The same logic is used for Linux and macOS state locations. The snippet does not
edit shell startup files or remove unrelated entries.

This fix is local and unreleased. The [original audit](BUG-HUNT-2026-09-26.md)
records the failure. Release work remains deferred.
