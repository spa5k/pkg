# BUG-04: repair a valid empty generation

Repair now recognizes a committed empty generation after validating its manifest,
lock outputs, activation roots, and local tree. It does not request a helper root
set for an empty closure. A damaged empty tree can still be reconstructed.
Unknown, unfinished, or invalid generations do not use this path.

This fix is local and unreleased. The [original audit](BUG-HUNT-2026-09-26.md)
records the failure. Release work remains deferred.

through BUG-04, based on `4ab212196956f9c53313fcd14521f737a84e98f0`.
