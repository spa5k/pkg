## Validation and artifact scope

Each fix has its own source checkpoint, command manifest, transcript, and check
record. Patches 3–9 are cumulative from `4ab2121`; do not apply them sequentially.
The final runtime patch and CLI/broker hashes are in the BUG-09 proof.
That proof also runs the final CLI with the fixed broker. It covers concurrent
doctor/removal, approval, rollback, command execution, both shells, and repair.
The final disposable VM is stopped at generation 31. Original failure evidence
is retained in its separate stopped VM.

Final Rust 1.96.1 workspace tests: **1,240 passed, zero failed, five ignored**.
Format, clippy, rustdoc, workspace build, cargo-deny, cargo-audit, and G-QUALITY
all pass. Commands and log hashes are recorded in
[checks.json](evidence/2026-09-26-bug09-fix/checks.json).
The latest G-QUALITY measurement is **922 sites across 23 lints**, down from
924 before these fixes. The shared baseline is unchanged.
