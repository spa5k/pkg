[issue #4](https://github.com/spa5k/pkg/issues/4). Independent E/Standards and
A/Spec/security reviews found no remaining source defects. The fixes are merged
and released in alpha.56, including final macOS wrapper and Linux profile
corrections. The [release proof](../release-lifecycle/ALPHA-56-2026-09-26.md)
records exact signed-byte lifecycle and UX checks.

alpha.54 CLI remains installed. Development services and `/tmp/pkg` were used
for these checks. The published broker was temporarily restored for ownership-
verified uninstall previews, then the development broker and helper were used
for GC. The final source refactor moved GC rendering to a helper and removed a
redundant uninstall scope sentence after this candidate build. The exact signed
alpha.56 tests now cover final release bytes in the linked release proof.

embedded trust input, and the replaced broker needed its exact published mode
restored. No uninstall mutation occurred. Case 011 correctly refused a preview
while GC held the state lease. Case 012 correctly rejected the existing two-just
output collision. The successful preview cases use explicit `keep-first`.

verification and doctor pass. The existing raw-Nix PATH warning is retained and
