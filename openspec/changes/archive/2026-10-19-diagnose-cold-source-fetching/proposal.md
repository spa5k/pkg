# Diagnose cold source fetching

## Why

Fresh-home installs spent extra time preparing pinned source trees. The cause had to be measured before selecting a runtime option.

## What Changes

- Measure default, eager-tree, and verified-NAR source preparation.
- Use private homes and preserve the shared host runtime.
- Select no product change because the ordered samples were mixed.

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- None.

## Impact

No production behavior changes. The consolidated measurements and limits are retained in the final speed record.
