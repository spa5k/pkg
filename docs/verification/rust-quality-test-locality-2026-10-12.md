Other grammar and command tests remain in `crates/pkg-cli/tests/cli.rs`. Each owner builds and runs the compiled CLI. Fixtures use real temporary files, profiles, snapshots, tap state, and call logs. The fake Nix executable supplies deterministic metadata and records child calls. Search preparation still checks six initial calls and four snapshot or marker files. The prepared-search owner then replaces Nix with a failing executable and proves later queries reuse the snapshot without another call.

One bounded mutation changed the native snapshot reader check from `check != "ok"` to `check == "ok"`. `prepared_catalogs_reuse_snapshot_without_runtime_calls` failed during setup because the published snapshot could not be read. The source was restored from the branch baseline. Its restored SHA-256 is `f9476f0e64702be0d143332b1e56b3c0dceed1633dfb5745dfef29737b688c47`. The failure log is `/tmp/pkg-rq3-test-locality-snapshot-mutation.log`.
